Pré-requisitos

  • Higgsfield MCP conectado + créditos (~$1–2 / site). Esta é a única coisa que o usuário deve configurar.
  • ffmpeg — NÃO peça ao usuário para instalá-lo. A Etapa 0 abaixo instala automaticamente (sem Homebrew).
  • Esta habilidade instalada em ~/.claude/skills/scroll-cinematic/.

Etapa 0 — Garantir ffmpeg (execute primeiro, sempre)

Execute bash ~/.claude/skills/scroll-cinematic/scripts/ensure-ffmpeg.sh. Ele usa o ffmpeg do sistema se presente, caso contrário baixa um binário estático para /tmp/ffmpeg-bin/ffmpeg (macOS/Linux, sem Homebrew). Os scripts de extração/compressão já usam esse caminho como alternativa. Nunca bloqueie a construção pelo ffmpeg.
